The `@redenv/client` package provides a lightweight, high-performance SDK for loading secrets in JavaScript and TypeScript applications.

## Quick Start

```typescript
import { Redenv } from "@redenv/client";

const redenv = new Redenv({
  project: "my-app",
  environment: "production",
  tokenId: process.env.REDENV_TOKEN_ID!,
  token: process.env.REDENV_TOKEN_KEY!,
  upstash: {
    url: process.env.UPSTASH_REDIS_URL!,
    token: process.env.UPSTASH_REDIS_TOKEN!,
  },
});

// Load and cache secrets
const secrets = await redenv.load();

// Access secrets
console.log(secrets.API_KEY);
console.log(secrets.DATABASE_URL);

// Also available in process.env
console.log(process.env.API_KEY);
```

## Configuration

### Required Options

| Option          | Type     | Description              |
| --------------- | -------- | ------------------------ |
| `project`       | `string` | Your project name        |
| `tokenId`       | `string` | Service Token public ID  |
| `token`         | `string` | Service Token secret key |
| `upstash.url`   | `string` | Upstash Redis REST URL   |
| `upstash.token` | `string` | Upstash Redis token      |

### Optional Options

| Option         | Type                            | Default         | Description                             |
| -------------- | ------------------------------- | --------------- | --------------------------------------- |
| `environment`  | `string`                        | `"development"` | Environment to load                     |
| `log`          | `"none"` \| `"low"` \| `"high"` | `"low"`         | Logging level                           |
| `cache.ttl`    | `number`                        | `300`           | Cache TTL in seconds                    |
| `cache.swr`    | `number`                        | `86400`         | Stale-while-revalidate window (seconds) |
| `env.override` | `boolean`                       | `true`          | Overwrite existing `process.env` values |

### Full Example

```typescript
const redenv = new Redenv({
  project: "my-app",
  environment: process.env.NODE_ENV || "development",
  tokenId: process.env.REDENV_TOKEN_ID!,
  token: process.env.REDENV_TOKEN_KEY!,
  upstash: {
    url: process.env.UPSTASH_REDIS_URL!,
    token: process.env.UPSTASH_REDIS_TOKEN!,
  },
  log: "high", // Enable detailed logging
  cache: {
    ttl: 600, // 10 minutes
    swr: 172800, // 48 hours
  },
  env: {
    override: false, // Don't overwrite existing env vars
  },
});
```

## API Reference

### `new Redenv(options)`

Create a new Redenv client instance.

**Returns:** `Redenv` instance

### `redenv.load()`

Fetch, decrypt, and cache all secrets for the configured environment.

```typescript
const secrets = await redenv.load();
```

**Returns:** `Promise<Secrets>`

**Behavior:**

- First call: Fetches from Redis, decrypts, caches
- Subsequent calls: Returns cached value (if fresh)
- Auto-populates `process.env` by default

### `redenv.init()`

Alias for `load()`. Useful for initialization at app startup.

```typescript
await redenv.init();
```

**Returns:** `Promise<void>`

### `redenv.set(key, value)`

Add or update a secret programmatically.

```typescript
await redenv.set("FEATURE_FLAG", "true");
```

**Parameters:**

- `key` - Secret key name
- `value` - New value

**Returns:** `Promise<void>`

**Note:** Requires a read-write Service Token.

### `redenv.getVersion(key, version, mode?)`

Fetch a specific version of a secret.

```typescript
// Get version 5
const v5 = await redenv.getVersion("API_KEY", 5);

// Get previous version (index mode)
const prev = await redenv.getVersion("API_KEY", 1, "index");

// Get oldest version
const oldest = await redenv.getVersion("API_KEY", -1);
```

**Parameters:**

- `key` - Secret key name
- `version` - Version number or index
- `mode` - `"id"` (default) or `"index"`

**Returns:** `Promise<string | undefined>`

## Secrets Object

The `Secrets` object returned by `load()` provides multiple ways to access secrets:

### Direct Access

```typescript
const secrets = await redenv.load();

// Get value (returns undefined if missing)
const apiKey = secrets.API_KEY;

// With type safety
const port: string = secrets.PORT;
```

### Methods

#### `secrets.get(key, options?)`

Get a secret value with optional default.

```typescript
// Simple get
const apiKey = secrets.get("API_KEY");

// With default
const port = secrets.get("PORT", { default: "3000" });
```

**Options:**

- `default` - Fallback value if key doesn't exist

#### `secrets.getAll()`

Get all secrets as a plain object.

```typescript
const allSecrets = secrets.getAll();
// { API_KEY: "...", DATABASE_URL: "...", ... }
```

#### `secrets.has(key)`

Check if a key exists.

```typescript
if (secrets.has("STRIPE_KEY")) {
  // Use Stripe
}
```

### Raw Values

Access unexpanded values (before secret expansion):

```typescript
console.log(secrets.API_URL); // Expanded: https://api.example.com/v1
console.log(secrets.raw.API_URL); // Raw: ${BASE_URL}/v1
```

## Caching Strategy

The SDK uses a sophisticated caching strategy for optimal performance:

### Stale-While-Revalidate

```
┌─────────────────┬──────────────────┬─────────────────┐
│  Fresh (0-5min) │  Stale (5min-24h)│  Expired (>24h) │
├─────────────────┼──────────────────┼─────────────────┤
│  Instant return │  Return cached   │  Fetch from     │
│  from cache     │  + fetch in bg   │  Redis (wait)   │
└─────────────────┴──────────────────┴─────────────────┘
```

**Benefits:**

- **Zero latency**: Stale data served instantly while refreshing
- **Resilience**: Works even if Redis is temporarily unavailable
- **Auto-updates**: Secrets refresh in background

### Cache Configuration

```typescript
const redenv = new Redenv({
  // ...
  cache: {
    ttl: 300, // Fresh for 5 minutes
    swr: 86400, // Serve stale up to 24 hours
  },
});
```

## Framework Integration

### Next.js App Router

```typescript
// lib/redenv.ts
import { Redenv } from "@redenv/client";

export const redenv = new Redenv({
  project: process.env.REDENV_PROJECT!,
  environment: process.env.NODE_ENV!,
  tokenId: process.env.REDENV_TOKEN_ID!,
  token: process.env.REDENV_TOKEN_KEY!,
  upstash: {
    url: process.env.UPSTASH_REDIS_URL!,
    token: process.env.UPSTASH_REDIS_TOKEN!,
  },
});
```

```typescript
// app/api/route.ts
import { redenv } from "@/lib/redenv";

export async function GET() {
  const secrets = await redenv.load();

  // Use secrets
  const apiKey = secrets.API_KEY;

  return Response.json({ status: "ok" });
}
```

### Express

```typescript
import express from "express";
import { Redenv } from "@redenv/client";

const app = express();

const redenv = new Redenv({
  // ...config
});

// Load secrets at startup
await redenv.init();

app.get("/", (req, res) => {
  // Secrets available in process.env
  res.json({ apiKey: process.env.API_KEY });
});

app.listen(3000);
```

### Serverless Functions (Vercel)

```typescript
// api/hello.ts
import { Redenv } from "@redenv/client";

const redenv = new Redenv({
  // ...config
});

export default async function handler(req, res) {
  const secrets = await redenv.load();

  res.json({ message: `API Key: ${secrets.API_KEY}` });
}
```

## Best Practices

### Environment-Based Configuration

```typescript
const redenv = new Redenv({
  project: "my-app",
  environment: process.env.NODE_ENV || "development",
  tokenId: process.env.REDENV_TOKEN_ID!,
  token: process.env.REDENV_TOKEN_KEY!,
  upstash: /* ... */
});
```

### Error Handling

```typescript
try {
  const secrets = await redenv.load();
} catch (error) {
  console.error("Failed to load secrets:", error);
  process.exit(1);
}
```

### Singleton Pattern

```typescript
// lib/redenv.ts
let instance: Redenv | null = null;

export function getRedenv() {
  if (!instance) {
    instance = new Redenv({
      // ...config
    });
  }
  return instance;
}
```

### Type Safety

```typescript
interface AppSecrets {
  API_KEY: string;
  DATABASE_URL: string;
  PORT: string;
}

const secrets = await redenv.load();

// Type assertion
const typedSecrets = secrets as unknown as AppSecrets;
```

## Troubleshooting

### "Missing required configuration options"

Ensure all required options are provided:

```typescript
const redenv = new Redenv({
  project: "...", // Required
  tokenId: "...", // Required
  token: "...", // Required
  upstash: {
    url: "...", // Required
    token: "...", // Required
  },
});
```

### Secrets not updating

Check cache configuration:

```typescript
const redenv = new Redenv({
  // ...
  cache: {
    ttl: 60, // Reduce TTL for faster updates
  },
});
```

### "Web Crypto API not available"

Ensure you're running in a compatible environment:

- Node.js 16+
- Deno 1.20+
- Bun 1.0+
- Modern browsers
