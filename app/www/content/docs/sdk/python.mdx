The `redenv` Python package provides both async and sync clients for loading secrets in Python applications.

## Installation

```bash
pip install redenv
```

**Requirements:**

- Python 3.8+
- Dependencies: `upstash-redis`, `cryptography`, `cachetools`

## Quick Start

### Async Client

```python
import asyncio
import os
from redenv import Redenv

async def main():
    client = Redenv({
        "project": "my-app",
        "environment": "production",
        "token_id": os.getenv("REDENV_TOKEN_ID"),
        "token": os.getenv("REDENV_TOKEN_KEY"),
        "upstash": {
            "url": os.getenv("UPSTASH_REDIS_URL"),
            "token": os.getenv("UPSTASH_REDIS_TOKEN")
        }
    })

    # Load secrets
    secrets = await client.load()

    # Access secrets
    print(secrets["API_KEY"])
    print(secrets["DATABASE_URL"])

    # Also available in os.environ
    print(os.environ["API_KEY"])

if __name__ == "__main__":
    asyncio.run(main())
```

### Sync Client

```python
import os
from redenv import RedenvSync

client = RedenvSync({
    "project": "my-app",
    "environment": "production",
    "token_id": os.getenv("REDENV_TOKEN_ID"),
    "token": os.getenv("REDENV_TOKEN_KEY"),
    "upstash": {
        "url": os.getenv("UPSTASH_REDIS_URL"),
        "token": os.getenv("UPSTASH_REDIS_TOKEN")
    }
})

# Load secrets (blocks until complete)
secrets = client.load()

print(secrets["API_KEY"])
```

## Configuration

### Required Options

| Option          | Type  | Description              |
| --------------- | ----- | ------------------------ |
| `project`       | `str` | Your project name        |
| `token_id`      | `str` | Service Token public ID  |
| `token`         | `str` | Service Token secret key |
| `upstash.url`   | `str` | Upstash Redis REST URL   |
| `upstash.token` | `str` | Upstash Redis token      |

### Optional Options

| Option         | Type   | Default         | Description                             |
| -------------- | ------ | --------------- | --------------------------------------- |
| `environment`  | `str`  | `"development"` | Environment to load                     |
| `log`          | `str`  | `"low"`         | Log level: `"none"`, `"low"`, `"high"`  |
| `cache.ttl`    | `int`  | `300`           | Cache TTL in seconds                    |
| `cache.swr`    | `int`  | `86400`         | Stale-while-revalidate window (seconds) |
| `env.override` | `bool` | `True`          | Overwrite existing `os.environ` values  |

### Full Example

```python
client = Redenv({
    "project": "my-app",
    "environment": os.getenv("ENV", "development"),
    "token_id": os.getenv("REDENV_TOKEN_ID"),
    "token": os.getenv("REDENV_TOKEN_KEY"),
    "upstash": {
        "url": os.getenv("UPSTASH_REDIS_URL"),
        "token": os.getenv("UPSTASH_REDIS_TOKEN")
    },
    "log": "high",  # Enable detailed logging
    "cache": {
        "ttl": 600,  # 10 minutes
        "swr": 172800  # 48 hours
    },
    "env": {
        "override": False  # Don't overwrite existing env vars
    }
})
```

## API Reference

### Async Client (`Redenv`)

#### `load()`

Fetch, decrypt, and cache all secrets.

```python
secrets = await client.load()
```

**Returns:** `Secrets` object

**Behavior:**

- First call: Fetches from Redis, decrypts, caches
- Subsequent calls: Returns cached value (if fresh)
- Auto-populates `os.environ` by default

#### `set(key, value)`

Add or update a secret programmatically.

```python
await client.set("FEATURE_FLAG", "true")
```

**Parameters:**

- `key` - Secret key name
- `value` - New value

**Note:** Requires a read-write Service Token.

#### `get_version(key, version, mode="id")`

Fetch a specific version of a secret.

```python
# Get version 5
v5 = await client.get_version("API_KEY", 5)

# Get previous version (index mode)
prev = await client.get_version("API_KEY", 1, mode="index")

# Get oldest version
oldest = await client.get_version("API_KEY", -1)
```

**Parameters:**

- `key` - Secret key name
- `version` - Version number or index
- `mode` - `"id"` (default) or `"index"`

**Returns:** `str | None`

### Sync Client (`RedenvSync`)

Same API as async client, but all methods are synchronous:

```python
secrets = client.load()  # No await
client.set("KEY", "value")  # No await
v = client.get_version("KEY", 5)  # No await
```

## Secrets Object

The `Secrets` object provides multiple ways to access secrets:

### Dictionary Access

```python
secrets = await client.load()

# Get value (returns None if missing)
api_key = secrets["API_KEY"]

# Check existence
if "STRIPE_KEY" in secrets:
    stripe_key = secrets["STRIPE_KEY"]
```

### Methods

#### `get(key, default=None, cast=None)`

Get a secret with optional default and type casting.

```python
# Simple get
api_key = secrets.get("API_KEY")

# With default
port = secrets.get("PORT", default="3000")

# With type casting
port = secrets.get("PORT", cast=int)  # Returns int
debug = secrets.get("DEBUG", cast=bool)  # Returns bool
timeout = secrets.get("TIMEOUT", default=30, cast=int)
```

**Supported casts:**

- `int` - Convert to integer
- `float` - Convert to float
- `bool` - Convert to boolean (`"true"`, `"1"` → `True`)
- `str` - Convert to string (default)

#### `require(*keys)`

Validate that required secrets exist. Raises error if any are missing.

```python
# Ensure critical secrets exist
secrets.require("API_KEY", "DATABASE_URL", "STRIPE_KEY")
```

**Raises:** `RedenvError` if any key is missing

#### `scope(prefix)`

Create a subset of secrets with a common prefix.

```python
# Get all STRIPE_* secrets with prefix removed
stripe = secrets.scope("STRIPE_")

print(stripe["KEY"])      # Maps to STRIPE_KEY
print(stripe["WEBHOOK"])  # Maps to STRIPE_WEBHOOK
```

**Returns:** New `Secrets` object with filtered keys

### Raw Values

Access unexpanded values (before secret expansion):

```python
print(secrets["API_URL"])      # Expanded: https://api.example.com/v1
print(secrets.raw["API_URL"])  # Raw: ${BASE_URL}/v1
```

## Framework Integration

### FastAPI

```python
from fastapi import FastAPI
from contextlib import asynccontextmanager
from redenv import Redenv
import os

# Initialize client
redenv_client = Redenv({
    "project": "my-app",
    "environment": os.getenv("ENV", "development"),
    "token_id": os.getenv("REDENV_TOKEN_ID"),
    "token": os.getenv("REDENV_TOKEN_KEY"),
    "upstash": {
        "url": os.getenv("UPSTASH_REDIS_URL"),
        "token": os.getenv("UPSTASH_REDIS_TOKEN")
    }
})

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Load secrets at startup
    await redenv_client.load()
    yield

app = FastAPI(lifespan=lifespan)

@app.get("/")
async def root():
    # Secrets available in os.environ
    return {"api_key": os.getenv("API_KEY")}
```

### Flask

```python
from flask import Flask
from redenv import RedenvSync
import os

app = Flask(__name__)

# Initialize sync client
client = RedenvSync({
    "project": "my-app",
    "token_id": os.getenv("REDENV_TOKEN_ID"),
    "token": os.getenv("REDENV_TOKEN_KEY"),
    "upstash": {
        "url": os.getenv("UPSTASH_REDIS_URL"),
        "token": os.getenv("UPSTASH_REDIS_TOKEN")
    }
})

# Load secrets before first request
@app.before_first_request
def load_secrets():
    client.load()

@app.route("/")
def index():
    return {"api_key": os.getenv("API_KEY")}

if __name__ == "__main__":
    app.run()
```

## Advanced Features

### Type Casting

```python
secrets = await client.load()

# Cast to int
port = secrets.get("PORT", cast=int)  # "3000" → 3000

# Cast to bool
debug = secrets.get("DEBUG", cast=bool)  # "true" → True

# Cast with default
timeout = secrets.get("TIMEOUT", default=30, cast=int)
```

### Scoping

Organize large configurations:

```python
secrets = await client.load()

# Require critical secrets
secrets.require("STRIPE_KEY", "STRIPE_WEBHOOK", "DATABASE_URL")

# Create scoped subsets
stripe_config = secrets.scope("STRIPE_")
aws_config = secrets.scope("AWS_")

# Use scoped secrets (prefix removed)
print(stripe_config["KEY"])      # STRIPE_KEY
print(stripe_config["WEBHOOK"])  # STRIPE_WEBHOOK
print(aws_config["REGION"])      # AWS_REGION
```

### Error Handling

```python
from redenv import RedenvError

try:
    secrets = await client.load()
except RedenvError as e:
    print(f"Failed to load secrets: {e}")
    exit(1)

# Validate required secrets
try:
    secrets.require("API_KEY", "DATABASE_URL")
except RedenvError as e:
    print(f"Missing required secrets: {e}")
    exit(1)
```

## Security

### Value Masking

Secrets are automatically masked when printed:

```python
print(secrets)
# Output: Secrets({'API_KEY': '********', 'DATABASE_URL': '********'})
```

This prevents accidental exposure in logs.

### Zero-Knowledge

All decryption happens locally. The Upstash server never sees plaintext values.

## Best Practices

### Environment-Based Configuration

```python
import os

environment = os.getenv("ENV", "development")

client = Redenv({
    "project": "my-app",
    "environment": environment,  # Dynamic!
    "token_id": os.getenv("REDENV_TOKEN_ID"),
    "token": os.getenv("REDENV_TOKEN_KEY"),
    "upstash": {
        "url": os.getenv("UPSTASH_REDIS_URL"),
        "token": os.getenv("UPSTASH_REDIS_TOKEN")
    }
})
```

### Singleton Pattern

```python
# config/redenv.py
from redenv import Redenv
import os

_client = None

def get_redenv():
    global _client
    if _client is None:
        _client = Redenv({
            # ...config
        })
    return _client
```

### Type Annotations

```python
from redenv import Secrets

async def get_config() -> Secrets:
    client = Redenv({...})
    return await client.load()
```
