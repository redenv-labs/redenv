# JavaScript SDK

The `@redenv/client` package allows you to fetch secrets in your Node.js, edge, or browser environments.

## Installation

<Tabs items={["npm", "pnpm", "yarn"]}>
  <Tab value="npm">npm install @redenv/client</Tab>
  <Tab value="pnpm">pnpm add @redenv/client</Tab>
  <Tab value="yarn">yarn add @redenv/client</Tab>
</Tabs>

## Usage

```typescript twoslash lineNumbers
import { Redenv } from "@redenv/client";

const client = new Redenv({
  project: "my-project",
  token: "my-token",
  tokenId: "my-token-id",
  upstash: {
    url: "https://upstash.com",
    token: "my-upstash-token",
  },
});

async function main() {
  const secrets = await client.load();
  const secret = secrets.get("my-secret");
  console.log(secret);
}

main();
```

## Features

- **Type-safe**: Built with TypeScript.
- **Universal**: Works in Node, Bun, Deno, and Edge runtimes.
- **Caching**: Built-in caching for performance.
