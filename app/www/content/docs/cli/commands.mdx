Complete reference for all Redenv CLI commands.

## Setup & Configuration

### setup

Configure Upstash Redis credentials.

```bash
redenv setup
```

**Prompts for:**

- Upstash Redis REST URL
- Upstash Redis Token

**Usage:**

```bash
redenv setup
```

### logout

Clear cached Master Password and credentials from system keychain.

```bash
redenv logout
```

## Project Management

### register

Create a new project with encrypted vault.

```bash
redenv register <project-name>
```

**Arguments:**

- `project-name` - Name of the project

**Prompts for:**

- Master Password (create new)
- Password confirmation

**Example:**

```bash
redenv register my-app
```

### drop

Delete a project and all its secrets permanently.

```bash
redenv drop [project-name]
```

**Arguments:**

- `project-name` - Optional, uses current project if omitted

**Flags:**

- `--force`, `-f` - Skip confirmation prompt

**Example:**

```bash
redenv drop my-app --force
```

### switch

Change active project or environment.

```bash
# Switch project
redenv switch project <project-name>

# Switch environment
redenv switch env <environment-name>
```

**Examples:**

```bash
# Switch to different project
redenv switch project my-other-app

# Switch to production environment
redenv switch env production
```

## Secret Operations

### add

Add or update a secret.

```bash
redenv add <key> [value]
```

**Arguments:**

- `key` - Secret key name
- `value` - Optional, prompts if omitted

**Examples:**

```bash
# Inline value
redenv add API_KEY "sk_test_123"

# Interactive (multi-line support)
redenv add DATABASE_URL
```

### edit

Edit a secret interactively in your default editor.

```bash
redenv edit <key>
```

**Arguments:**

- `key` - Secret key name

**Example:**

```bash
redenv edit API_KEY
# Opens $EDITOR with current value
```

### view

Display a secret's current value.

```bash
redenv view <key>
```

**Arguments:**

- `key` - Secret key name

**Flags:**

- `--version <n>` - View specific version

**Examples:**

```bash
# View current value
redenv view API_KEY

# View version 2
redenv view API_KEY --version 2
```

### list

List all secrets in current environment.

```bash
redenv list
```

**Flags:**

- `--full` - Show full values (default: truncated)
- `--json` - Output as JSON

**Example:**

```bash
redenv list --full
```

### remove

Delete a secret and its version history.

```bash
redenv remove <key>
```

**Arguments:**

- `key` - Secret key name

**Flags:**

- `--force`, `-f` - Skip confirmation

**Example:**

```bash
redenv remove OLD_API_KEY --force
```

## Import/Export

### import

Import secrets from `.env` file or stdin.

```bash
redenv import [file]
```

**Arguments:**

- `file` - Optional, reads from stdin if omitted

**Flags:**

- `--overwrite` - Overwrite existing secrets

**Examples:**

```bash
# From file
redenv import .env.production

# From stdin
cat .env | redenv import

# From stdin with overwrite
redenv import --overwrite < .env.local
```

### export

Export secrets to `.env` format.

```bash
redenv export [file]
```

**Arguments:**

- `file` - Optional, writes to stdout if omitted

**Flags:**

- `--env <name>` - Export from specific environment

**Examples:**

```bash
# To stdout
redenv export

# To file
redenv export > .env.local

# Specific environment
redenv export --env production > .env.prod
```

## Environment Operations

### clone

Copy all secrets from one environment to another.

```bash
redenv clone <source> <target>
```

**Arguments:**

- `source` - Source environment name
- `target` - Target environment name

**Flags:**

- `--force`, `-f` - Overwrite target without confirmation

**Example:**

```bash
redenv clone production staging
```

### diff

Compare secrets between two environments.

```bash
redenv diff <env1> <env2>
```

**Arguments:**

- `env1` - First environment name
- `env2` - Second environment name

**Example:**

```bash
redenv diff development production
```

### sync

Add a secret to multiple environments at once.

```bash
redenv sync <key> <value> --environments <env1>,<env2>
```

**Arguments:**

- `key` - Secret key name
- `value` - Secret value

**Flags:**

- `--environments`, `-e` - Comma-separated environment list

**Example:**

```bash
redenv sync SHARED_CONFIG "value" --environments dev,staging,prod
```

## Version History

### history view

View all versions of a secret.

```bash
redenv history view <key>
```

**Arguments:**

- `key` - Secret key name

**Flags:**

- `--full` - Show complete values (default: truncated)

**Example:**

```bash
redenv history view API_KEY --full
```

### history limit

Set or view version retention limit.

```bash
# View current limit
redenv history limit

# Set limit
redenv history limit <count>

# Remove limit
redenv history limit --unlimited
```

**Arguments:**

- `count` - Number of versions to keep

**Flags:**

- `--unlimited` - Remove limit, keep all versions

**Examples:**

```bash
# View limit
redenv history limit

# Keep last 10 versions
redenv history limit 10

# Keep all versions
redenv history limit --unlimited
```

### rollback

Restore a previous version of a secret.

```bash
redenv rollback <key> [--version <n>]
```

**Arguments:**

- `key` - Secret key name

**Flags:**

- `--version <n>` - Version to restore (default: previous)

**Examples:**

```bash
# Rollback to previous version
redenv rollback API_KEY

# Rollback to specific version
redenv rollback API_KEY --version 3
```

## Service Tokens

### token create

Generate a new Service Token for application access.

```bash
redenv token create <name> [--read-only]
```

**Arguments:**

- `name` - Token identifier/description

**Flags:**

- `--read-only` - Create read-only token

**Examples:**

```bash
# Read-write token
redenv token create ci-cd-pipeline

# Read-only token
redenv token create app-production --read-only
```

### token list

View all Service Tokens for current project.

```bash
redenv token list
```

**Example:**

```bash
redenv token list
```

### token revoke

Invalidate a Service Token immediately.

```bash
redenv token revoke <token-id>
```

**Arguments:**

- `token-id` - Token ID to revoke

**Example:**

```bash
redenv token revoke tok_abc123
```

## Security & Backup

### change-password

Update Master Password for current project.

```bash
redenv change-password
```

**Prompts for:**

- Current Master Password
- New Master Password
- Password confirmation

**Example:**

```bash
redenv change-password
```

### backup

Export encrypted project metadata to a file.

```bash
redenv backup [file]
```

**Arguments:**

- `file` - Optional, defaults to `redenv-backup-<timestamp>.json`

**Example:**

```bash
# Default filename
redenv backup

# Custom filename
redenv backup my-backup.json
```

### restore

Import project metadata from a backup file.

```bash
redenv restore <file>
```

**Arguments:**

- `file` - Backup file path

**Flags:**

- `--force`, `-f` - Overwrite existing project

**Example:**

```bash
redenv restore my-backup.json
```

### doctor

Diagnose configuration and connectivity issues.

```bash
redenv doctor
```

**Checks:**

- Upstash Redis connection
- Project configuration
- Master Password cache status

**Example:**

```bash
redenv doctor
```

## Execution

### shell

Run a command with secrets injected as environment variables.

```bash
redenv shell -- <command>
```

**Arguments:**

- `command` - Command to execute

**Examples:**

```bash
# Run development server
redenv shell -- npm run dev

# Execute script
redenv shell -- node script.js

# Run with arguments
redenv shell -- python app.py --port 3000
```

## Registry

### registry

View all registered projects.

```bash
redenv registry
```

**Shows:**

- Project names
- Current environment
- Last accessed

**Example:**

```bash
redenv registry
```

## Global Flags

Available on most commands:

- `--help`, `-h` - Show command help
- `--version`, `-v` - Show CLI version

## Exit Codes

- `0` - Success
- `1` - Error (generic)
- `2` - Authentication error
- `3` - Not found error
