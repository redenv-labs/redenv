---
title: env
description: Delete one or more environments from a project.
---

The `drop env` command permanently deletes environments from a project.

<Callout type="error">
  **This action is irreversible!** All secrets and version history in the
  deleted environments will be permanently lost. Create a backup with `redenv
  backup` before proceeding.
</Callout>

## Usage

```bash
redenv drop env [environments...]
```

## Arguments

| Name           | Required | Description                                            |
| -------------- | -------- | ------------------------------------------------------ |
| `environments` | No       | Environment name(s) to delete (interactive if omitted) |

## Options

| Flag                   | Description  |
| ---------------------- | ------------ |
| `-p, --project <name>` | Project name |

## Examples

```bash
# Delete interactively
redenv drop env

# Delete specific environment
redenv drop env staging

# Delete multiple environments
redenv drop env staging testing
```

## Interactive Flow

