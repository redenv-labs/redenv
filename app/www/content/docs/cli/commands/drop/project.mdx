The `drop project` command permanently deletes projects and all their environments.

<Callout type="error">
  **This action is irreversible!** All secrets, environments, and version
  history will be permanently deleted. Create a backup with `redenv backup`
  before proceeding.
</Callout>

## Usage

```bash
redenv drop project [projects...]
```

## Arguments

| Name       | Required | Description                                        |
| ---------- | -------- | -------------------------------------------------- |
| `projects` | No       | Project name(s) to delete (interactive if omitted) |

## Examples

```bash
# Delete interactively (checkbox selection)
redenv drop project

# Delete specific project
redenv drop project old-app

# Delete multiple projects
redenv drop project old-app test-project
```
