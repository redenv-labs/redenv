The Redenv CLI is a command-line tool for managing encrypted secrets across environments. It handles the complete secret management lifecycle — from project creation to deployment.

<Callout type="info">
  **Zero-Knowledge by Design** — All encryption happens on your machine. The CLI
  uses AES-256-GCM with PBKDF2 key derivation. Your Master Password never leaves
  your device.
</Callout>

## Installation

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">```bash npm install -g @redenv/cli ```</Tab>
  <Tab value="pnpm">```bash pnpm add -g @redenv/cli ```</Tab>
  <Tab value="yarn">```bash yarn global add @redenv/cli ```</Tab>
  <Tab value="bun">```bash bun add -g @redenv/cli ```</Tab>

See the [Installation Guide](/docs/installation) for detailed instructions and troubleshooting.

## First-Time Setup

Connect the CLI to your Upstash Redis instance:

```bash
redenv setup
```

You'll be prompted for your **Upstash Redis REST URL** and **REST Token** — both available in your [Upstash Console](https://console.upstash.com?utm_source=redenv_dev&utm_medium=docs). Credentials are stored securely in your system keychain.

## Quick Examples

**Create a project and add secrets:**

```bash
redenv register my-app
redenv add API_KEY "sk_test_123"
redenv add DATABASE_URL "postgresql://localhost/myapp"
redenv list
```

**Work with multiple environments:**

```bash
redenv switch env production
redenv add API_KEY "sk_live_xyz"
redenv diff development production
```

**Migrate from `.env` file:**

```bash
redenv register my-app
redenv import .env
```

**Enter interactive mode:**

```bash
redenv shell
# Now run commands without 'redenv' prefix
> add API_KEY "value"
> list
> exit
```

## Configuration

Create a `redenv.config.ts` in your project root:

```typescript
import { defineConfig } from "@redenv/core";

export default defineConfig({
  name: "my-app",
  environment: "development",
  plugins: [],
});
```

The CLI discovers configuration in this order:

1. `redenv.config.ts` in current directory
2. `redenv.config.ts` in parent directories
3. Global config from `redenv setup`
